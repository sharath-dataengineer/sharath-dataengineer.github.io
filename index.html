Iceberg Health Monitor

A 0–100 health score for every Iceberg table

Iceberg tables degrade without any error. Small files, snapshot buildup, manifest growth, partition skew and stale partitions slow queries and raise cost long before anyone notices. This open-source tool scans table metadata, runs six analyzers, and recommends compaction, snapshot expiry or partition redesign. It ships as a CLI and a REST API.

  • Apache Iceberg
  • Python
  • CLI + REST
  • Compaction
  • Table health

Pipeline health monitor with AI advisory

Failure risk predicted before the run fails

A SparkListener feeds stage metrics to a LightGBM risk model, a policy engine tiers the alerts, and an LLM writes a root-cause advisory for the serious ones. Manual log triage went away.

How I work

Positions I design against and defend in architecture reviews.

  • Observability is the load-bearing wall.Every pipeline emits freshness, volume and schema signals before it emits business data.
  • Data quality failures are architecture failures.Constraints go in at ingestion, with contracts between producers and consumers and gates in CI.
  • Cost is an engineering responsibility.Each compute dollar maps to a team, a pipeline and an outcome, visible at design time.
  • Leverage comes from standards.Golden paths, written decisions and shared patterns make the next ten engineers faster.
